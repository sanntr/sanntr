## 🚀 Proyectos destacados

### LSC Model — *En desarrollo*
> Pipeline de ML para reconocimiento de Lengua de Señas Colombiana en tiempo real

Modelo LSTM entrenado con el dataset LSC70. Usa MediaPipe HandLandmarker para extracción de landmarks con normalización en dos pasos. Estructurado como scripts independientes (ETL → preprocesamiento → entrenamiento → exportación), orientado a servirse como API REST SaaS.

> 🚧 *Proyecto activo — pipeline en construcción, entrenamiento y exportación del modelo en progreso.*

`Python` · `TensorFlow` · `MediaPipe` · `LSTM`

[![Ver repositorio](https://img.shields.io/badge/GitHub-LSC__model-181717?style=flat-square&logo=github)](https://github.com/sanntr/LSC_model)

---

### 💬 Uchat — *En mejora continua*
> Chatbot con inteligencia artificial para estudiantes

Aplicación web con Django que integra RAG (Retrieval-Augmented Generation) para responder preguntas en contexto educativo. Incluye sistema de usuarios, módulo de chat y flujos de CI/CD con GitHub Actions.

> 🔄 *Proyecto activo — funcional y en evolución, con mejoras continuas en curso.*

`Python` · `Django` · `RAG` · `HTML/CSS` · `JavaScript`
